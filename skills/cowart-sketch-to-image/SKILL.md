# Cowart Sketch to Image

Use this skill when the user points at a hand-drawn sketch on the Cowart canvas and
wants a finished image that follows its composition. The sketch is **structure
guidance**, not content to copy literally.

## Preconditions

The Cowart service should be running for the active project, usually at:

```text
http://127.0.0.1:43217
```

The user identifies which shapes form the sketch — usually by selecting them. Do not
guess across the whole canvas; if the sketch shapes are ambiguous, ask the user to
select them or name them.

## Workflow

1. Identify the sketch shapes.

   Prefer the user's current selection (`get_cowart_selection`, or the Cowart MCP
   `get_cowart_canvas` to inspect shapes on the current page). The sketch is typically
   `draw` strokes plus `geo`/`arrow`/`text` layout shapes the user drew.

2. Export the sketch as a reference image.

   Use the Cowart MCP `export_cowart_view` tool with the sketch as the target and
   `returnBase64: true`, so you get the image bytes directly without reading a file:

   ```json
   {
     "mode": "selection",
     "format": "png",
     "background": false,
     "returnBase64": true
   }
   ```

   Use `mode: "shapes"` with explicit `shapeIds` when you want a precise subset rather
   than the live selection. The exported PNG is also written to `outputPath`.

3. Read any labels in the sketch (optional).

   If the sketch contains `text` shapes or `geo` labels, read them with
   `get_cowart_canvas` and fold their wording into the generation prompt (e.g. a box
   labelled "hero" should become the hero area).

4. Generate the finished image.

   Call the built-in `image_gen` tool with the exported sketch as an **input image /
   structure reference** plus a text prompt describing the desired result. The prompt
   should:

   - follow the sketch's composition, proportions, and the position of labelled regions
   - render a clean finished image — do **not** reproduce sketch strokes, layout boxes,
     arrows, or handwriting in the output
   - match the sketch's aspect ratio unless the user asks otherwise

   Choose a generation size with the sketch's aspect ratio (a valid size for the model,
   e.g. dimensions divisible by 16, aspect between 1:3 and 3:1).

5. Insert the result beside the sketch.

   Prefer the Cowart MCP `insert_cowart_image` tool and pass the generated bytes
   **as base64** (the `image_generation_call.result`) via `imageBase64` — no file
   hunting:

   ```json
   {
     "imageBase64": "<image_generation_call.result base64>",
     "anchorShapeId": "<a shape in the sketch, or a frame around it>",
     "placement": "right",
     "margin": 40,
     "altText": "Image generated from a Cowart sketch",
     "shapeMeta": { "cowartGeneratedFromSketch": true }
   }
   ```

   If the user selected an `AI 图片` holder for the output, use `fillAnchor: true` with
   that holder instead.

6. Verify.

   Refresh or let the browser hot-reload, then confirm:

   - the original sketch is unchanged and still in place
   - the generated image sits beside the sketch and follows its layout
   - the output contains no sketch strokes, boxes, arrows, or handwriting

## Guardrails

- Never modify, move, or delete the sketch shapes; they are the user's input.
- Treat the sketch as composition guidance, not literal content — strip sketch artifacts
  from the output.
- If the selection is empty or the sketch is ambiguous, ask the user to select the
  sketch shapes rather than scanning the whole canvas.
- Keep canvas data in the project workspace via Cowart's page-local assets (the MCP
  tools handle this); never overwrite an existing asset without an explicit request.
